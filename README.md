# Black Crown Media — WebDevPro Ultra Max 4 Rebrand

GitHub/Vercel-ready static website for Black Crown Media.

## Deploy
1. Upload all files in this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: **Other / Static** (no build command required).
4. Root directory: repository root.

Includes PWA manifest, service worker, mobile footer navigation, hero slider/typewriter, animations and compact WhatsApp enquiry chatbot.
